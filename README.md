# BiLyRuSh Albion Merchant

Web app sencilla para comparar precios de recursos de Albion Online en el servidor Americas usando datos públicos de Albion Online Data Project.

## Uso
Selecciona recurso, tier, encantamiento y cantidad. Pulsa **Escanear todos los markets**.

## Ciudades
Bridgewatch, Martlock, Lymhurst, Fort Sterling, Thetford y Caerleon.

## Nota
Los datos dependen de actualizaciones de AODP. La app muestra la antigüedad del dato y marca cifras viejas para verificar.
